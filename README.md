## 💻 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de criar uma presença digital de alto padrão para a área da saúde. A interface foi construída para transmitir acolhimento, autoridade e exclusividade, utilizando uma paleta de cores terrosas e tipografia elegante.

Tecnicamente, o foco foi entregar performance máxima e interações fluidas sem depender de bibliotecas pesadas, manipulando o DOM e as animações através de **Vanilla JavaScript** e **Tailwind CSS**.

## ✨ Principais Funcionalidades & UX/UI

- **Design Editorial (Premium):** Composição baseada em espaços negativos, tipografia contrastante (Serif e Sans-Serif) e cores quentes (beges e marrons).
- **Animações Nativas (Scroll Reveal):** Implementação de `Intersection Observer` nativo do JavaScript para criar efeitos de surgimento em cascata e *fade-in-up* de forma performática.
- **Waveform Dinâmico:** Animação de espectro de áudio gerada via JavaScript e CSS puro, que calcula a largura da tela para preencher o fundo de ponta a ponta simulando uma gravação vocal.
- **Microinterações Fluídas:** Botões com efeitos de escala, sombras dinâmicas e transições suaves nos itens (hover effects).
- **Accordion Interativo:** Seção de "Dúvidas Frequentes" com controle de abertura e fechamento suave (`max-height` transitions).
- **Smart WhatsApp Routing:** CTAs inteligentes que redirecionam o usuário para o WhatsApp com mensagens pré-preenchidas dinâmicas (ex: agendamento vs. dúvidas gerais).
- **Mobile-First & Responsividade Extrema:** Menu *drawer* lateral personalizado e layouts de grid que se adaptam perfeitamente a smartphones, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica visando acessibilidade e SEO.
- **Tailwind CSS:** Estilização utilitária ágil, configuração de temas (cores estendidas) e animações (`animate-pulse`, `delay-[]`).
- **JavaScript (Vanilla):** Lógica para menu mobile, accordions, geração procedural da onda sonora e `Intersection Observer` para scroll animado.
- **Lucide Icons:** Biblioteca de ícones SVG leves e consistentes.
- **Google Fonts:** Utilização das fontes *Playfair Display* (títulos) e *Plus Jakarta Sans* (textos).
